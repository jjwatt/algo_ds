# Python Algorithms and Data Structures

Unified Python workspace managed with Nix (`use flake ..#python`) and `uv` (`pyproject.toml`).

## Structure

- `myalgs/`: Custom data structures, sorting/search implementations, and *The Algorithm Design Manual* (`tadm/`) exercises.
- `leetcode/`: LeetCode problem solutions.
- `hackerrank/`: HackerRank problem solutions.
- `neetcode/`: NeetCode problem solutions.
- `ctci/`: *Cracking the Coding Interview* solutions.
- `scratch/`: Experimental scripts and benchmarks.
